1. Brief Overview
-Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides on-demand computing resources over the internet, such as servers, storage, databases, networking, security, and analytics. Instead of purchasing and maintaining physical servers, organizations can use AWS resources and pay based on their usage.

2. Global Infrastructure
AWS has a global infrastructure made up of:
Regions – Geographic areas where AWS operates data centers.
Availability Zones (AZs) – Separate locations within an AWS Region designed to provide high availability and fault tolerance.
Edge Locations – Locations used by services such as Amazon CloudFront to deliver content closer to users.
This infrastructure allows businesses to deploy applications closer to their customers and improve reliability and performance.

3. Cloud Management Console
-The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create, configure, monitor, and delete cloud resources through the console without needing to use command-line tools.
For example, administrators can use the console to launch a virtual server, create a database, manage storage, configure security settings, and monitor applications.

4. Four (4) Core Services
AWS Service	Description
-Amazon EC2	Provides virtual servers that organizations can use to run applications and websites.
-Amazon S3	Provides scalable object storage for files, images, videos, backups, and other data.
-Amazon RDS	Provides managed relational databases, reducing the need to manually manage database servers.
-Amazon VPC	Allows organizations to create and manage isolated virtual networks for their AWS resources.

6. Three (3) Advantages
1. Scalability
AWS allows businesses to increase or decrease computing resources based on demand. This is useful when an application suddenly receives a large number of users.
2. Cost Efficiency
Organizations do not necessarily need to purchase expensive physical servers and data-center equipment. AWS generally uses a pay-as-you-go pricing model, allowing businesses to pay for the resources they use.
3. Reliability and Availability
AWS's global infrastructure, including multiple Availability Zones, helps organizations build applications that can remain available even when individual infrastructure components experience failures.

6. Typical Enterprise Use Cases
AWS is commonly used by enterprises for:
-Web and application hosting – Running websites, APIs, and business applications.
-Data backup and storage – Storing company files, backups, and archives using services such as Amazon S3.
-Database management – Hosting business databases using services such as Amazon RDS.
-Disaster recovery – Maintaining backup systems and data in the cloud so organizations can recover from infrastructure failures.
-Big data and analytics – Processing and analyzing large amounts of business data.
-Software development and testing – Creating temporary development and testing environments without purchasing additional physical servers.
-Machine learning and AI – Building and deploying AI and machine-learning applications using AWS cloud resources.
